# Sicherheit

Dieses Repository enthält den gemeinsamen Code der Lern-Apps zur Kristallographie (statische Webseiten ohne Server, Konto oder Übertragung von Daten). Unterstützt wird jeweils nur das neueste Release. Betrifft eine Lücke eine App, kann sie auch dort gemeldet werden.

## Eine Sicherheitslücke melden

Bitte **nicht als öffentliches Issue**. Stattdessen im Repository unter **Security → Report a vulnerability** eine private Meldung anlegen ([Anleitung](https://docs.github.com/de/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)). Hilfreich sind die betroffene Version und Datei sowie die Schritte, mit denen sich die Lücke zeigen lässt.
